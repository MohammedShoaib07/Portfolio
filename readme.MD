# Mohammed Shoaib — Portfolio

A minimal, single-page portfolio website built with plain HTML, CSS, and JavaScript. No frameworks, no build step — just open and go.

🔗 **Live site:** https://mdshoaibportfolio.vercel.app

## Overview

This site highlights:
- **Experience** — leadership roles (AIML Department Forum, IEEE SIGHT)
- **Selected Work** — Pothole Detection & Reporting App, HackJury, VeriPass
- **Achievements** — hackathon wins and participation
- Dark/light mode toggle
- Live clock (Bengaluru, IST)
- Local visitor counter

## Tech Stack

- HTML5
- CSS3 (custom properties, no framework)
- Vanilla JavaScript
- Google Fonts (Newsreader + Inter)

## Project Structure

```
├── index.html      # Page markup and content
├── style.css       # All styling, layout, and dark mode
└── script.js       # Clock, theme toggle
```


## Customizing

- **Content:** edit the text directly inside `index.html`.
- **Colors/fonts:** update the CSS custom properties at the top of `style.css` (`:root` and `body.dark`).
- **Links:** update email, phone, GitHub, and LinkedIn URLs in the intro section of `index.html`.
